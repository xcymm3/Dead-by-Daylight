# 格区调度台

一个本地运行的 React 单人格子对局。选择人类或屠夫后，电脑扮演另一方。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开终端显示的本地地址。点击「开始演练」，在地图上选择出生点。轮到你时，点击高亮格子移动或翻越，在行动面板里修机、放板或结束行动。完整规则可以从页面顶部打开。

屠夫界面及电脑屠夫共用同一份可见状态。人类的格子、已修机器的具体位置和行动明细会隐藏，放下的木板会在挡住或砸中屠夫时显露。

两面墙位于 C2 和 C4。出口开放后，人类可从已放下木板的左侧或右侧点击木板，斜翻进入对应出口并获胜。

```powershell
npm.cmd test
npm.cmd run build
```
