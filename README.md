# 格区调度台

一个 React 回合制格子对局，支持单人演练和好友联机。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开终端显示的本地地址。点击「开始演练」，在地图上选择出生点。轮到你时，点击高亮格子移动或翻越，在行动面板里点灯、放板或结束行动。完整规则可以从页面顶部打开。

开局可以选择普通或困难。普通使用原版人机。困难屠夫用合法观测维护候选局面，并优先采用有限步内能确保获胜的走法。困难人类会推演屠夫巡逻并规划点灯、撤离路线。

屠夫界面及电脑屠夫共用同一份可见状态。人类的位置、具体亮起的灯和行动明细会隐藏。屠夫在试图通过已放下的木板或被木板砸晕时，才会发现板已放下。

场地四周围墙，C2 和 C4 是内部墙段，C3 是窗户。C1 和 C5 的木板开局靠在通道左上端，放下后往右下搭住通道。点亮 3 盏灯后，在 A3 点击西门或在 E3 点击东门即可离开地图。

对局结束后可查看本局回放。从双方出生位置开始，用「上一回合」「下一回合」查看每回合结束时的地图和双方坐标。浏览器只保存最近一局已结束的回放，可从配置页重新打开。中途返回配置不会覆盖已有记录。

## 好友联机

保持前端终端运行，在第二个终端启动房间服务。

```powershell
npm.cmd run online:server
```

在两个独立浏览器标签页打开前端，点击「好友联机」。一方创建房间，另一方输入六位房间码加入。房主先选角色，来宾扮演另一方并确认准备，房主再点击「开始对战」。角色决定对局内的出场和行动顺序。

刷新原标签页或短暂断网时，页面会尝试自动重连。对手断线时对局暂停，服务端检测到断线后会保留座位 10 分钟。主动退出会关闭未结束的房间。结算后双方均可逐回合查看完整回放，浏览器会用本局覆盖上一局回放。

### 公网部署

React 前端可以继续作为静态站点发布，例如部署到 EdgeOne Pages。房间服务需要运行在可保持 WebSocket 连接的 Node.js 进程中。它默认监听 `127.0.0.1:8787`，支持通过 `ONLINE_HOST` 和 `ONLINE_PORT` 配置监听地址。

- **同域部署**　通过支持 WebSocket 升级的 HTTPS 反向代理，把前端同域的 `/online` 转发到房间服务。
- **分开部署**　为房间服务配置对外的 TLS 入口，在前端构建环境中设置 `VITE_ONLINE_URL=wss://rooms.example.com/online` 后重新发布。在房间服务设置 `ONLINE_ORIGINS=https://你的前端域名`，限制允许连接的浏览器来源。

房间和进行中的对局保存在服务进程内存中。部署重启会清空房间，已保存在浏览器里的回放仍可查看。
