# 格区调度台

一个本地运行的 React 单人格子对局。选择人类或屠夫后，电脑扮演另一方。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开终端显示的本地地址。点击「开始演练」，在地图上选择出生点。轮到你时，点击高亮格子移动或翻越，在行动面板里点灯、关门或结束行动。完整规则可以从页面顶部打开。

屠夫界面及电脑屠夫共用同一份可见状态。人类的位置、具体亮起的灯和行动明细会隐藏。屠夫在试图通过已关的门或被关上的门撞晕时，才会发现门已关上。

场地四周围墙，C2 和 C4 是内部墙段，C3 是窗户，C1 和 C5 是开局开启的门。点亮 3 盏灯后，站在 A3 可进入左侧地窖，站在 E3 可进入右侧地窖。

对局结束后可查看本局回放。从双方出生位置开始，用「上一回合」「下一回合」查看每回合结束时的地图和双方坐标。浏览器只保存最近一局已结束的回放，可从配置页重新打开。中途返回配置不会覆盖已有记录。

```powershell
npm.cmd test
npm.cmd run build
```
